FEU ALABANG RECEPTION PORTAL — ENHANCED OPERATIONAL BUILD

Key updates
1. Live Operational Control is now connected to the existing portal state.
   - Time-In is the first priority.
   - Standard opening tasks follow attendance.
   - Notifications surface required actions and operational issues.
2. Manual Time-In/Time-Out and Standard Tasks now use the existing local-first cloud queue.
   - Local action is preserved immediately.
   - When Google Apps Script is configured and online, changes are queued/sent to PortalData.
   - The dashboard clearly shows GOOGLE SHEETS LIVE or LOCAL CACHE.
3. Opening checklist expanded to seven source-based reception tasks.
4. Reception Handbook reorganized into 10 operational categories.
   - Cards are clickable.
   - Each procedure opens a detailed step-by-step view.
   - Policy-controlled values from the supplied draft remain marked for confirmation.
5. Existing portal modules, login flow, favicon, VES links, certification, games, and settings were preserved.

Cloud setup
- Open Settings > Google Apps Script Cloud Database.
- Enter the approved Google Apps Script Web App URL ending in /exec.
- Test Connection.
- The portal will remain usable locally if cloud service is unavailable.
